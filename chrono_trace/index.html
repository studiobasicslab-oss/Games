⏳ How to Play ChronoTrace

1. The Premise

History has fractured into a tangled web of events. As a Time Weaver, you must navigate from an Origin Event (Start Node) to a Culmination Event (End Node).

2. The Rule of Directionality

A step from Event A to Event B is valid if and only if Year(A) ≤ Year(B). Node timestamps are initially hidden (???) and revealed upon traversal.

3. Anachronism Paradoxes (Traps)

If you connect a node from 1969 to a neighbor node that occurred in 1945, the connection fractures, inflicting a Timeline Paradox penalty.

4. Thematic Synergies & Bonuses

Linking consecutive events of matching categories (🔬 Science, ⚔️ Politics, 🎨 Culture, 🧭 Discovery) triggers Resonance Multipliers and massive score boosts.

5. Game Modes & Relics

Daily Web: 1 global puzzle per day with shareable cards.
Causal Chains: 12 handcrafted story chapters.
Fog of Time: Rogue-lite mode with fog-of-war and power-up Relics (Chronometer Lens, Paradox Shield, Temporal Anchor).
