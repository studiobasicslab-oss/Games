Periodic Snake Protocol

Welcome, Researcher! Your task is to safely guide the biochemical snake to consume correct elements from the Periodic Table in order of atomic weight / number (starting with 1-Hydrogen, up to 118-Oganesson).

Safe Operations Rules:

  • Watch the Target Element Box in the dashboard before making a decision.
  • Look for that exact element tile on the canvas.
  • The canvas spawns 1 Correct target element and 3 random incorrect elements.
  • If you collide with an incorrect element, it will cause an unstable chemical cascade, and you will lose 1 reactor life.
  • Steer using arrow keys, WASD, swipe gestures, or the onscreen D-Pad interface.
