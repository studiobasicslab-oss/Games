🧠 Microarchitecture Codex & Rules

1. Out-of-Order (OoO) Dispatch: Drag and reorder instructions in the Reservation Station to bypass instructions waiting for operands (RAW hazards).

2. RAW Hazards (Read-After-Write): An instruction cannot execute if its source register is still being calculated by an active ALU or LSU.

3. Branch Prediction: The 2-bit predictor guesses whether jumps are Taken or Not Taken. Mispredictions flush the pipeline, wasting 3 cycles!

4. Cache Hierarchy: L1 Cache responds in 1 cycle. L2 Cache responds in 3 cycles. Main RAM misses take 8 cycles.

5. IPC Metric: Instructions Per Cycle = (Retired Instructions / Clock Cycles). Keep it as high as possible!
